CRM SYSTEM

CRM System — це full-stack вебзастосунок для керування користувачами, проєктами та задачами.

Проєкт створено як фінальну практичну роботу після вивчення React, Node.js, NestJS, TypeScript, MySQL та основ побудови клієнт-серверних застосунків.

1. ОСНОВНІ МОЖЛИВОСТІ

Система підтримує три ролі користувачів:

ADMIN

* створення нових користувачів;
* перегляд усіх користувачів;
* редагування користувачів;
* активація та деактивація облікових записів;
* створення, редагування та видалення проєктів;
* створення, редагування та видалення задач;
* перегляд усіх проєктів і задач;
* доступ до загальної статистики.

MANAGER

* перегляд призначених проєктів;
* перегляд задач у своїх проєктах;
* створення та редагування задач;
* призначення задач робітникам;
* зміна статусів задач;
* перевірка виконаних задач;
* перегляд активних робітників.

WORKER

* перегляд лише тих проєктів і задач, до яких користувача призначено;
* зміна дозволених статусів задач;
* перегляд дедлайнів, пріоритетів і деталей задач.

4. АРХІТЕКТУРА ПРОЄКТУ

Production-версія працює за такою схемою:

Frontend на Netlify
|
| HTTP-запити
v
Backend NestJS на Render
|
| SQL-запити через TypeORM
v
MySQL-база на Aiven

Frontend не підключається до бази даних напряму.

Усі запити проходять через NestJS backend, який перевіряє авторизацію, роль користувача, права доступу та валідність даних.

5. АВТОРИЗАЦІЯ

У застосунку використовується JWT-авторизація.

Після успішного входу backend створює:

* access token;
* refresh token.

Access token використовується для доступу до захищених маршрутів.

Refresh token зберігається в HTTP-only cookie та використовується для автоматичного отримання нового access token.

Axios interceptor обробляє помилки 401 і виконує запит на оновлення токена.

Для одночасних невдалих запитів використовується черга, щоб не надсилати кілька refresh-запитів одночасно.
