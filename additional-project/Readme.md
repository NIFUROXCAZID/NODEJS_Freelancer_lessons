СЕРВІС ПОСТАВОК АВТОМОБІЛІВ

Fullstack вебзастосунок для управління каталогом та поставками автомобілів.

Проєкт створено з навчальною метою для практики сучасної fullstack-розробки та побудови клієнт-серверних застосунків.

Застосунок дозволяє переглядати каталог автомобілів, працювати з детальною інформацією про них, виконувати пошук, фільтрацію та сортування, а керувати записами залежно від ролі користувача і додавати їх в корзину.

ОСНОВНІ МОЖЛИВОСТІ

У застосунку реалізовано:

JWT-авторизацію;
розмежування прав доступу за ролями;
CRUD-операції над автомобілями;
створення, редагування та видалення записів;
перегляд детальної інформації про автомобіль;
завантаження зображень;
роботу з брендами автомобілів;
роботу з постачальниками;
пошук;
фільтрацію;
сортування;
пагінацію;
infinite scroll;
REST API;
захищені маршрути;
обробку помилок;
взаємодію frontend та backend через HTTP-запити.
РОЛІ КОРИСТУВАЧІВ

У системі передбачено декілька рівнів доступу.

Залежно від ролі користувач може:

переглядати каталог автомобілів;
переглядати детальну інформацію;
створювати нові автомобілі;
редагувати існуючі записи;
видаляти автомобілі;
Додавати їх в корзину.

Перевірка прав доступу виконується як на frontend, так і на backend.

БАЗА ДАНИХ

У проєкті використовується MongoDB.

Для роботи з MongoDB використовується Mongoose.

Основні сутності:

Products / Cars;
Brands;
Owners / Suppliers;
Users.

Між автомобілями, брендами та постачальниками використовуються зв'язки через MongoDB ObjectId та Mongoose populate.

АВТОРИЗАЦІЯ

У застосунку використовується JWT-авторизація.

Після успішного входу користувач отримує доступ до функцій відповідно до своєї ролі.

Для роботи з авторизацією використовуються:

access token;
refresh token;
cookies;
захищені backend-маршрути;
захищені frontend-маршрути.

Frontend використовує Axios для роботи з API та обробки авторизаційних запитів.

ЗАВАНТАЖЕННЯ ЗОБРАЖЕНЬ

Для автомобілів можна завантажувати зображення.

Backend обробляє файли за допомогою Multer.

Завантажені файли зберігаються окремо та доступні frontend для відображення фотографій автомобілів.

ФІЛЬТРАЦІЯ ТА СОРТУВАННЯ

Каталог підтримує роботу з параметрами запиту.

Користувач може використовувати:

фільтр за брендом;
фільтр за постачальником;
мінімальну ціну;
максимальну ціну;
сортування;
напрямок сортування.

Frontend формує параметри запиту, а backend виконує відповідну фільтрацію у базі даних.

ПАГІНАЦІЯ

Для великих списків автомобілів використовується серверна пагінація.

Backend повертає:

поточну сторінку;
кількість елементів;
інформацію про наступну сторінку;
список автомобілів.

Це дозволяє не завантажувати весь каталог одним запитом.

INFINITE SCROLL

Окрім звичайної пагінації, у проєкті реалізовано сторінку з infinite scroll.

Під час прокручування сторінки IntersectionObserver визначає момент, коли користувач наближається до кінця списку.

Після цього frontend автоматично запитує наступну сторінку автомобілів та додає її до вже завантажених даних.

REST API

Frontend та backend працюють як окремі частини застосунку.

Схема взаємодії:

React frontend
|
| HTTP / Axios
v
Node.js + Express backend
|
| Mongoose
v
MongoDB

Frontend не працює з MongoDB напряму.

Усі операції з даними проходять через REST API.

ПРИКЛАДИ API

Авторизація:

POST /auth/login
POST /auth/logout
POST /auth/refresh

Автомобілі:

GET /products
GET /products/
POST /products
PATCH /products/
DELETE /products/

Додаткові маршрути можуть використовуватися для роботи з брендами, постачальниками та користувачами.
